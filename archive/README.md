# Semester archives

Create one directory per archived offering, using lowercase season and year names:

```text
archive/
  fall-2024/
    index.html
  fall-2025/
    index.html
```

All archive pages reuse the root `style.css` through `../../style.css`. The root `index.html` remains the current offering. See the repository's main `README.md` for the archiving checklist.
